How to download your bank statement
SBI
  1. Login to onlinesbi.sbi
  2. Go to My Accounts → Account Statement
  3. Select date range
  4. Click Download as Excel
HDFC
  1. Login to netbanking.hdfcbank.com
  2. Go to My Accounts → Account Statement
  3. Select date range
  4. Download as CSV/Excel
ICICI
  1. Login to icicibank.com
  2. Go to Accounts → Statement
  3. Select date range
  4. Download as Excel
Google Pay
  1. Open GPay app
  2. Tap profile icon
  3. Go to Transaction History
  4. Download statement

How to get Gmail App Password:
  1. Go to myaccount.google.com
  2. Click Security on the left
  3. Enable 2-Step Verification (if not already)
  4. Search for "App passwords" in the search bar
  5. Select app: Mail → Select device: Other
  6. Type "ExpenseTrack" → Click Generate
  7. Copy the 16-character password shown
