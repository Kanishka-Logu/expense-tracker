How to download your bank statement
SBI
  1. Login to onlinesbi.sbi
  2. Go to My Accounts → Account Statement
  3. Select date range
  4. Click Download as Excel
HDFC
  1. Login to netbanking.hdfcbank.com
  2. Go to My Accounts → Account Statement
  3. Select date range
  4. Download as CSV/Excel
ICICI
  1. Login to icicibank.com
  2. Go to Accounts → Statement
  3. Select date range
  4. Download as Excel
Google Pay
  1. Open GPay app
  2. Tap profile icon
  3. Go to Transaction History
  4. Download statement (PDF/CSV)
